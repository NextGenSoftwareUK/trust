WEB6 & Advanced Features

Control how Leela routes requests and which advanced OASIS reasoning features are active. WEB6 routing sends requests through the OASIS WEB6 API layer — required for FAHRN and Holonic Braid. Direct mode calls the selected provider's API without the WEB6 layer (faster for Leela AI).

Route through WEB6
When on, all provider requests are sent through the OASIS WEB6 API — enabling avatar context, semantic caching, and the features below. When off, Leela AI is called directly (other providers still use WEB6 as they have no direct key configured here).
WEB6 reasoning features (require WEB6 routing)
FAHRN — Fractal Adaptive Holonic Reasoning Network
Runs a multi-agent reasoning-network dispatch before calling the provider. FAHRN scores sub-agents by task type (trust-guidance) and injects an execution plan into the system context — improving answer quality for complex queries at the cost of latency.
Holonic Braid — shared reasoning graph
Fetches the collective Holonic BRAID reasoning graph for the trust-guidance task type and injects it into the system context. Enriches responses with patterns learned across the OASIS holonic network.
