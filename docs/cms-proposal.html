Background

Why we don't need a third-party CMS

Most platforms bring in an off-the-shelf content management system — products like Sanity, Contentful, or Prismic — when they need the ability to update website content without involving a developer. For SovereignTrust, that would mean paying for a separate subscription, learning a separate tool, and creating a dependency on an outside vendor.

SovereignTrust already runs on OASIS — a platform that has its own flexible data storage, its own user system, and its own API. We can build content management directly on top of what is already there. The result is simpler, cheaper, and entirely under your control.

In plain terms: your team will be able to update page copy, FAQs, pricing, and trust form templates from a simple admin screen — the same admin area you already have — with no third-party logins, no subscriptions, and no developer needed for routine content changes.

The three options

What's included in each option

The work is split into three modules. Each one can be delivered on its own or combined with the others — you choose the scope that fits right now, and can add more later.

A
Content CMS

Your team can update the site's text — the education page, FAQs, pricing copy, and legal disclaimers — without involving a developer. Changes go live immediately from a simple editor screen.

B
Admin Dashboard

A full view of everything happening on the platform. See all user trust documents, search by name or status, view account details, handle support queries, and manage user records — all in one place.

C
Trust Template Builder

Create entirely new types of trust, add or reorder the fields on existing ones, set what's required, and control how the final PDF looks — all without any code changes or developer involvement. This is the most powerful of the three modules and the largest piece of work.
